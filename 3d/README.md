# COS-HUMA 3D — M1.1 test build (skeleton)

Test build only. The live 2D app at the repository root is unchanged and is not linked from here except by the "📖 2D" button.

## Open
- Test URL (serves this branch over HTTPS): https://raw.githack.com/xgridseurope/cos-huma/m1.1-test/3d/index.html
- Diagnostics panel: tap ⚙︎ in the header, or add `?diag=1`.
- Diagnostic fallback (embedded model, same geometry as the .glb): `?model=embedded`. Normal loads use `models/cos-huma-skeleton.glb`.

## Files
- `index.html`, `app.js` — app (no build step); `vendor/` — three.js r186 (MIT)
- `data/curriculum.json` — knowledge data generated by `tools/curriculum-source.py`, checked word by word against textbook pp.25 and 27 (labels exactly as printed, lower case). Every field carries a status (`textbook` / `pending` / `none` / `not-in-textbook`). Exercises may only use `exam: true` items and fields with status `textbook`. `tools/test-textbook.mjs` checks the 21 skeleton labels against p.25.
- `models/` — adapted BodyParts3D model, CC BY-SA 2.1 JP (see `LICENSE-MODEL.txt`, `ATTRIBUTION.txt`)
- `tools/build-skeleton.mjs` — rebuilds the model from the OrganUI GLBs (commits listed in ATTRIBUTION.txt)
- `tools/test-m11.mjs` — headless checks; these do not replace real-device tests

## Rebuild
```
npm i
node tools/build-skeleton.mjs <organui skeleton.glb> <organui muscles.glb> models/cos-huma-skeleton.glb
```
